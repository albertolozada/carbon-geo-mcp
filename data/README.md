# Data

## Sample data (`data/sample/`)

All files are **synthetic and fictional**, generated by [`scripts/make_sample_data.py`](../scripts/make_sample_data.py). They are stored in EPSG:4326 on purpose, because project layers often arrive in degrees.

| File | Content |
|---|---|
| `project_strata.gpkg` | 3 strata (`dense_forest`, `open_forest`, `non_forest`) of a fictional 8,000 ha project, field `stratum` |
| `protected_area.gpkg` | A fictional reserve overlapping the project by 150 ha |
| `plots.gpkg` | 40 monitoring plots, fields `plot_id` and `stratum` |
| `lossyear_sample.tif` | Hansen-style loss-year raster (0.00025°, value 15 = 2015 ... 24 = 2024) |

## Real forest loss data

For real projects, use the `lossyear` layer of the Hansen / UMD / Google / USGS / NASA **Global Forest Change** dataset (CC BY 4.0). It is distributed in 10 x 10 degree GeoTIFF tiles named by their north-west corner (for example `20S_070W`). Download the tile(s) covering your area from the dataset's download page and pass the local file to `forest_loss_in_area`. If your area spans several tiles, mosaic them first (for example with `gdalbuildvrt`).
